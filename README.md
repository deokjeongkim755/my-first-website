# 花生创客基地

这是一个面向 9–10 岁孩子的 Scratch 3 中文学习网站，采用“乐高搭建”的视觉思路来讲解编程步骤。

## 打开方式

直接用浏览器打开 `index.html` 即可。页面主体无需联网；观看视频时需要连接互联网。

## 页面包含

- 花生角色原创插画和明亮、有行动感的视觉设计
- Scratch 四个起步动作：认舞台、选角色、拖积木、点绿旗
- 五个站点的分步骤操作地图
- 可交互的 Scratch 界面定位提示
- 三个可以马上动手的操作任务
- 入门、条件循环和全套课程三个精选视频入口

学习完成标记保存在当前浏览器的本地存储中，不会上传。

## 文件说明

- `index.html`：页面内容
- `styles.css`：视觉设计和响应式布局
- `script.js`：教学切换、学习进度、视频弹窗和动画演示
- `assets/illustrations/`：页面使用的原创角色插画
- `assets/peanut-mascot.svg`：网站的原创花生角色
